## ⚙️ Handling common issues

Most users find the installation simple, but you might run into these common situations:

### The application will not open
If the software does not start, ensure you have sufficient RAM available. Close other programs that use large amounts of memory before starting NeoSketch. Restarting your computer often fixes temporary conflicts with administrative permissions.

### The filter takes a long time to apply
The speed of the process depends on your processor. High-resolution images require more compute cycles. If you notice a slow response, use smaller images or close background applications to free up system resources.

### Windows Defender shows a prompt
Because this is a standalone software, Windows might show a warning message. If you receive a "Windows protected your PC" prompt, click "More info" and then select "Run anyway." This message occurs because the application is not part of a common commercial software package.

### Errors during image export
Ensure you have permission to write files to the folder you selected. If you try to save to a system-protected drive, the application might fail to create the file. Choose a location in your Pictures or Documents folder instead.
